# Example Context Import Report

## Proposed Subject

The supplied material appears to describe one product rather than its parent organization. Create a product Context Project and keep organization background to the minimum required for ownership and brand interpretation.

## Candidate Current Facts

- The command-line interface is in public beta.
- Billing remains available only in the web application.

## Conflict Requiring Confirmation

The README calls the CLI generally available, while the release notes call it public beta. Treat availability as disputed until the team confirms which statement is current.

## Historical Material

The private-beta invitation flow is historical and should not enter ordinary task exports.

## Missing Critical Context

- Supported operating systems
- Whether public-beta usage has separate limits

## Proposed Structure

Use `templates/product.md`. Keep availability in `Capabilities And Limits`, the terminology decision in `Confirmed Decisions`, and unresolved release status in `Open Questions`.
